# Google Cybersecurity Professional Certificate — Portfólio

Este repositório documenta minha evolução durante o **Google Cybersecurity Professional Certificate**. Aqui reúno anotações escritas com minhas próprias palavras, atividades de portfólio e projetos práticos desenvolvidos ao longo da formação.

## Objetivo

Construir uma base sólida para atuar em segurança cibernética, com foco inicial em funções como **Cybersecurity Analyst** e **SOC Analyst**, e demonstrar o aprendizado por meio de documentação e prática.
