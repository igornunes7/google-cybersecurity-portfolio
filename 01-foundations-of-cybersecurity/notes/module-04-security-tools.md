# Módulo 4 — Ferramentas e conceitos técnicos

## Logs, SIEM e playbooks

Um **log** é um registro de eventos que ocorrem nos sistemas de uma organização.

Uma ferramenta **SIEM** coleta e analisa dados de logs para ajudar a monitorar atividades críticas.

Um **playbook** é um manual com detalhes sobre as ações que devem ser executadas em uma atividade operacional.

## IDS e análise de tráfego

Um **Intrusion Detection System (IDS)** monitora atividades e alerta sobre possíveis intrusões.

Um analisador de protocolos de rede, também chamado de **packet sniffer**, captura e analisa o tráfego de uma rede. O **Wireshark** é um exemplo dessa ferramenta.

## SQL e bancos de dados

Um **banco de dados** armazena dados de uma organização.

**Structured Query Language (SQL)** é uma linguagem usada para criar e manipular bancos de dados e consultar as informações armazenadas neles.

## Python

Python é uma linguagem de programação que pode ser usada para automatizar tarefas repetitivas, demoradas ou que exigem precisão e atenção a detalhes.

## Criptografia e codificação

A **criptografia** converte dados legíveis, chamados de texto simples, em texto cifrado. Seu objetivo é impedir que pessoas não autorizadas compreendam os dados e, assim, ajudar a preservar a confidencialidade.

Codificação e criptografia têm finalidades diferentes. A **codificação** usa um método público de conversão para permitir o compartilhamento de informações entre sistemas que usam representações de dados diferentes; ela não tem como objetivo principal proteger o conteúdo contra acesso não autorizado.

## Teste de penetração

O teste de penetração (**penetration testing** ou **pentest**) é um ataque simulado e autorizado que ajuda a identificar vulnerabilidades em sistemas, redes, sites, aplicações e processos.

## Ordem de volatilidade

A ordem de volatilidade descreve a sequência em que dados digitais devem ser preservados, começando pelos que podem desaparecer mais rapidamente.
